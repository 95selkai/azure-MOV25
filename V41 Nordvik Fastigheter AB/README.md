# Vecka 41 – Slutuppgift Microsoft Azure

## Nordvik Fastigheter AB

### Syfte
Syftet med projektet är att planera och implementera en säker hyresgästportal i Microsoft Azure.

Hyresgäster ska kunna göra felanmälningar genom att ange rubrik, beskrivning och bifoga en bild.

### Projektets delar
1. Compute – webbportal i Azure
2. IAM – användare och behörigheter
3. Nätverk och säkerhet
4. Storage – lagring av bilder och dokument
5. Infrastructure as Code – ARM-mallar
6. Power Automate – automatisering av felanmälningar
7. Dokumentation och verifiering

### Verktyg
- Microsoft Azure
- PowerShell
- GitHub
- Microsoft Entra ID
- Power Automate
